02
What the backend gates & stores
ACCESS CONTROL
  • Desktop mode injects a UI token
  • _desktop_ui_token_gate → 403 for any non-desktop client (HTTP + WS)
  • Plain-browser mode: no gate, LAN-reachable
SESSION STORE
  • 1 Project = 1 session.json
  • Documents/ASRA Projects/<name>/
  • findings · logs · hypotheses · chat threads · map_manual (hand-placed nodes)
  • sibling file, not in session.json: toolkit/traffic.jsonl
  • computed, not stored: attack-surface graph (recon+findings+chain — always on) · site map tree (toolkit traffic only, empty if nothing was proxied)
LIVE STREAMS
  • /session/{id}/stream — log/findings
  • /session/{id}/chat/stream — chat
  • /session/{id}/toolkit/screencast/stream — browser live-view
DEBUG / LOGGING
  • 15 categories, one shared color map
  • Global: Documents/ASRA/debug.log
  • Per-project: next to that project's session.json
