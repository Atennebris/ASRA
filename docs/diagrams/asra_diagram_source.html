03
Chat, subagents & the approval gate
CHAT — MULTI-THREADED
A layer, not a sidebar
Own threads, own tool loop, auto-compaction when long. Can inject live "guidance" into an autonomous pass already running via an instruction queue — and a standalone "Quick Chat" needs no session at all.
SUBAGENTS
Real delegation, not aspirational
Explicitly called by the model, or auto-delegated when recon/analyze/exploit overflows a phase's own budget. Results are drained back into the parent pass or delivered straight into chat.
APPROVAL GATE
Per-finding, then session-wide
The first real exploitation attempt in a session pauses on a live asyncio.Event for one operator click — that decision then covers the rest of the session. Every outcome logged.
