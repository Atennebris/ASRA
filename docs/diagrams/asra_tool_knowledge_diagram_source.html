A host that fails three real dispatches in a row gets marked dead for the rest of the phase — every further tool call against it is skipped. A build-command/argument mistake never counts toward that streak, only a genuine timeout/connection failure does.
03
Beyond raw dispatch — operator & agent share a surface
TOOLKIT — SHARED TRAFFIC STORE
Burp-style, both directions
Proxy/Repeater/Intruder/Sequencer/Comparer/Decoder read & write one traffic store — the operator drives it by hand, the agent hits the same store through 4 bridged tool calls.
BROWSER — AGENT-DRIVEN
Real Playwright, stateful
A genuine JS-executing Chromium session the agent drives across separate tool calls — dispatched on the main event loop, never the generic thread pool, because Playwright's own objects are loop-pinned.
TERMINAL — OPERATOR ONLY
No agent path in at all
A real PTY shell, exempt from the exploitation allowlist on principle — opening it is the authorization. The model cannot reach it.
