03
Beyond a single call
RESERVE PROVIDERS
Ordered fallback chain
An explicit, multi-step list of provider/model pairs (Settings). On failure the next step is tried in order — several rows on the same provider is how "try these models here, in order" is expressed.
SECONDARY VERIFICATION
A second, different model re-checks
Opt-in: every Critical/High "verified" finding is independently re-examined by a genuinely different provider/model. Disagreement is surfaced, never silently resolved by picking one.
TOOL-CALLING MODE
Native, with a prompt-based fallback
Detected per model. A provider that rejects native function-calling on a given call transparently switches to prompt-based tool-calling for the rest of that session.
