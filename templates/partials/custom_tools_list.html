Custom tools

Binaries you've registered yourself, discovered via "Test path" above or added directly with "Add custom tool" -- ASRA's own registry has no builder for these at all. Each ENABLED one becomes a real, named tool, using whichever flags its own usage text below documents, and its own "Available to" switches decide which consumers actually get it (main agent, chats, reverse/ interactive modes, subagents). Runs sandboxed (the same process/filesystem isolation custom- script tools already get), since this project has no track record with an arbitrary added binary the way it does with its own built-in tools.
